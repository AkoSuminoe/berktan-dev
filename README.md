# berktan.dev

Personal developer portfolio website for Berktan.

## Overview
This is a personal developer portfolio designed to be responsive, reactive, and visually stunning. It will be hosted on a personal server and accessible via `berktan.dev`.

## Planned Features
- **Responsive Design**: Optimized for both mobile and desktop experiences.
- **Beautiful Animations**: Smooth, modern, and reactive UI elements.
- **Tailwind CSS**: Styling powered by Tailwind CSS.
- **GitHub Integration**: Automatically fetches and displays projects from GitHub.
- **Professional Links**: Integration with LinkedIn and an accessible CV/Resume.

## Project Structure
- `src/`: Source code.
  - `components/`: Reusable UI components.
  - `pages/` (or `app/`): Application routes.
  - `styles/`: Global stylesheets and Tailwind configuration.
  - `utils/`: Helper functions.
- `public/`: Static assets like images and icons.
